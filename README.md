# SolatKini Malaysia (v2.5.0)

Aplikasi waktu solat moden, penentu arah kiblat berketepatan tinggi, dan peringatan azan luar talian berteraskan piawaian data rasmi Jabatan Kemajuan Islam Malaysia (JAKIM)[span_0](start_span)[span_0](end_span). Dibina dengan mengutamakan privasi, sifar iklan, dan penjimatan bateri optimum[span_1](start_span)[span_1](end_span).

---

## Ciri-Ciri Utama

* **Takwim Rasmi JAKIM (60 Zon)**: Penyelarasan langsung mengikut pangkalan data e-Solat JAKIM serta sandaran algoritma matematik falak luar talian[span_2](start_span)[span_2](end_span).
* **Penggera Azan Tepat Masa**: Menggunakan servis penggera tepat Android (`AlarmManager`) yang kekal beroperasi tanpa disekat oleh pengoptimuman bateri[span_3](start_span)[span_3](end_span).
* **7 Koleksi Muadzin Luar Talian**: Pilihan alunan azan berkualiti tinggi dari muadzin JAKIM Malaysia, Makkah, Madinah, Al-Aqsa, dan laungan khas Subuh[span_4](start_span)[span_4](end_span).
* **Kompas Kiblat Geodesik**: Pengiraan trigonometri unjuran sfera Kaabah Makkah (21.4225° U, 39.8262° T) dengan sokongan getaran haptik[span_5](start_span)[span_5](end_span).
* **Privasi Penuh & Sifar Iklan**: Bebas iklan komersial sepenuhnya, sifar penjejakan data peribadi, dan pemprosesan GPS setempat tanpa pelayan luar[span_6](start_span)[span_6](end_span).
