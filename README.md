# SolatKini Malaysia (v2.5.0)

Aplikasi waktu solat moden, penentu arah kiblat berketepatan tinggi, dan peringatan azan luar talian berteraskan piawaian data rasmi Jabatan Kemajuan Islam Malaysia (JAKIM). Dibina dengan mengutamakan privasi, sifar iklan, dan penjimatan bateri optimum.

---

## Ciri-Ciri Utama

* **Takwim Rasmi JAKIM (60 Zon)**: Penyelarasan langsung mengikut pangkalan data e-Solat JAKIM serta sandaran algoritma matematik falak luar talian.
* **Penggera Azan Tepat Masa**: Menggunakan servis penggera tepat Android (`AlarmManager`) yang kekal beroperasi tanpa disekat oleh pengoptimuman bateri.
* **7 Koleksi Muadzin Luar Talian**: Pilihan alunan azan berkualiti tinggi dari muadzin JAKIM Malaysia, Makkah, Madinah, Al-Aqsa, dan laungan khas Subuh.
* **Kompas Kiblat Geodesik**: Pengiraan trigonometri unjuran sfera Kaabah Makkah (21.4225° U, 39.8262° T) dengan sokongan getaran haptik.
* **Privasi Penuh & Sifar Iklan**: Bebas iklan komersial sepenuhnya, sifar penjejakan data peribadi, dan pemprosesan GPS setempat tanpa pelayan luar.
